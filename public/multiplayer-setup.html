Connect your online estuary

The public connection key is already configured. You do not need a secret key, a paid plan or the Supabase CLI.

Owner setup is needed once. The normal game works without these steps.

1. Install the game database

  1. Open your Supabase SQL Editor ↗. Sign in if asked. If it opens the editor list, click New query.
  2. Press Copy database setup below, then paste it into the empty SQL editor.
  3. Click the green Run button. The script adds only the game's er_* tables and functions. It can be run again safely. It does not erase existing account or game data.
  4. You should see Success. No rows returned. If you get an error, copy the error message back into the chat.
Download SQL instead

2. Set the email return address

  1. Open Authentication → URL Configuration ↗.
  2. Set Site URL to .
  3. Add that same address to Redirect URLs, then save.

Keep email confirmation enabled. Supabase's built-in email sender has limits and may only send to addresses authorized by your project. If friends cannot receive email, configure your own SMTP provider in Authentication → Email. No SMTP password belongs in the game.

3. Play with a friend

  1. Open Estuary Rats and choose ONLINE / ACCOUNT.
  2. Enter your email and a password of at least 8 characters. Press CREATE ACCOUNT. Confirm the email, then sign in. Use RESET PASSWORD if needed; after following that email, open Online → Set a new password.
  3. Choose a player name. Press JOIN PUBLIC WORLD, or CREATE PRIVATE ROOM and give the 8-character code to your friend.
  4. Press DRIVE WITH FRIENDS. Your friend needs their own account and must join the same world. Both of you should meet near The Wharf.

There is one public world, capped at 8 players. Private rooms also hold 8 and expire after 24 hours. Offline members expire after 45 seconds; rejoin if your tab slept. One account controls one craft. Player poses update about 3 times a second with smoothing. The online button displays connection status.

First-release limits

Player craft, paint, position, trim, rider pose and deck position are shared. Local AI boats, weather selection, fishing, races, scoring and spray flooding remain local. There is no online player damage, chat, voice, economy synchronization or authoritative anti-cheat server. Room codes keep casual visitors out; anyone given the code can join. Supabase usage and transfer limits apply.

The Supabase publishable key is intentionally public. Permissions in the SQL protect player records: clients cannot read tables directly or write another player's pose. Never put a secret/service-role key in this game.
