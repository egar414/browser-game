Connect your online estuary

The public connection key is already configured. You do not need a secret key, a paid plan or the Supabase CLI.

Owner setup is needed once. The normal game works without these steps.

1. Install the game database

  1. Open your Supabase SQL Editor ↗. Sign in if asked. If it opens the editor list, click New query.
  2. Press Copy database setup below, then paste it into the empty SQL editor.
  3. Click the green Run button. The script adds only the game's er_* tables and functions. It can be run again safely. It does not erase existing account or game data.
  4. You should see Success. No rows returned. This installs the game database; it does not assign a Creator badge. Complete the separate Creator step below for that. If you get an error, copy the error message back into the chat.

2. Set the email return address

  1. Open Authentication → URL Configuration ↗.
  2. Set Site URL to .
  3. Add that same address to Redirect URLs, then save.

Email confirmation is optional. Enable it when you have a working email sender; the quick setup below allows unverified addresses. Supabase's built-in email sender has limits and may only send to addresses authorized by your project. If friends cannot receive email, configure your own SMTP provider in Authentication → Email. No SMTP password belongs in the game.

Email problems: rate limit exceeded

Supabase's built-in email sender has a small sending allowance. Repeated Create Account or Reset Password attempts will not bypass it. The game cannot change that project setting using a public key.

Quick setup without email verification:

  1. Open Authentication → Sign In / Providers ↗, then select Email.
  2. Turn Confirm email off and save. Password accounts still work, but email addresses are not verified.
  3. Return to the game and press CREATE ACCOUNT once with the same email and password. If already registered, use SIGN IN. Do not keep retrying email requests.

To keep verified email accounts: leave Confirm email on and configure your own SMTP sender under Authentication → Email. A provider may require a domain. Password reset emails also need a working sender or an available email allowance.

3. Play with a friend

  1. Open Estuary Rats and choose ONLINE / ACCOUNT.
  2. Enter your email and a password of at least 8 characters. Press CREATE ACCOUNT. If email confirmation is enabled, confirm the email and sign in. With confirmation off, your account is ready immediately. Use RESET PASSWORD if needed; after following that email, open Online → Set a new password.
  3. Choose a player name. Press JOIN PUBLIC WORLD, or CREATE PRIVATE ROOM and give the 8-character code to your friend.
  4. Press DRIVE WITH FRIENDS. Your friend needs their own account and must join the same world. Both of you should meet near The Wharf.

There is one public world, capped at 8 players. Private rooms also hold 8 and expire after 24 hours. Offline members expire after 45 seconds; rejoin if your tab slept. One account controls one craft. Player poses update about 3 times a second with smoothing. The online button displays connection status.

Optional: your verified Creator tag

If yours is the only game account, the simpler single-account Creator setup SQL installs the badge and assigns that sole account. Copy all of it into a new SQL query and Run. Look for Creator enabled in Results, then Refresh Account in the game. It refuses to guess when multiple accounts exist.

The project owner can give their own game account a gold CREATOR badge, the personal reference-sculpted Sparkplug, all garage designs and tuning, and 2× local garage XP. Other players see the gold tag. This does not grant database administration, access to other accounts or online damage powers.

  1. Sign in to your game account, open ONLINE / ACCOUNT and click OWNER SETUP / CREATOR TAG. Open this guide from that link so it knows which account to grant.
  2. Copy the creator setup below and run it in your SQL Editor ↗. Only the Supabase project owner can grant badges.
  3. Return to the game's Online panel and press REFRESH ACCOUNT, or join your room again.

Keep your role attached to your account UUID. Changing a display name or editing local saved settings cannot grant the badge to another player. The creator update can be run more than once.

First-release limits

Player craft, paint, position, trim, rider pose and deck position are shared. Local AI boats, weather selection, fishing, races, scoring and spray flooding remain local. There is no online player damage, chat, voice, economy synchronization or authoritative anti-cheat server. Room codes keep casual visitors out; anyone given the code can join. Supabase usage and transfer limits apply.

The Supabase publishable key is intentionally public. Permissions in the SQL protect player records: clients cannot read tables directly or write another player's pose. Never put a secret/service-role key in this game.

Automatic online spray and sinking

Download the owner database update. In Supabase SQL Editor, open a new query, paste the entire file and Run. Existing accounts and Creator grants stay in place. Reload the game afterwards.

No consent prompts: spray hits count in public and private rooms. Private room codes let you choose your company. Falling spray adds water, full boats sink for six seconds, then relaunch with eight seconds of protection. The server counts hits within the same room; it never accepts a client-supplied victim or damage amount.
