The GitHub integration can publish the game but its repository-rename request
returned HTTP 403, `Resource not accessible by integration`. The repository
owner needs to complete this one action:

1. Open https://github.com/egar414/browser-game/settings .
2. Under General → Repository name, enter `estuary-rats` and click Rename.

After the rename, update the local Git remote to
`https://github.com/egar414/estuary-rats.git`, update and commit the README,
third-party source link and hosted-test URLs, push and check the Pages
workflow. Verify the new public URL before replacing the current play link.
GitHub repository redirects do not guarantee a redirect for the old Pages URL.

A separate domain such as `estuaryrats.com` needs a domain owned by the user
and its DNS settings; no domain purchase or DNS change has been performed.
